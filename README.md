# Claude Wide Chat

Chrome extension that expands Claude.ai's chat width for better readability.

## Features
- Adjustable chat width (50-98%)
- Configurable side padding
- Text alignment (left, center, right, justify)
- Real-time preview
- Settings sync across devices

## Install
[Chrome Web Store](your-store-link-here) or load unpacked from this repo.

## Dev
Built with vanilla JS/CSS. No build step - edit and reload.
